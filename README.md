# Sales Data Analysis

## 📊 Project Overview

This project analyzes sales data to identify sales trends, product performance, regional performance, and overall business profitability.

The project demonstrates an end-to-end Data Analyst workflow using **Python, SQL, and Power BI**.

## 🛠️ Tools & Technologies

* Python
* Pandas
* SQL
* Power BI
* CSV Dataset

## 📁 Dataset

The cleaned dataset contains **1,000 sales records** and includes information such as:

* Order ID
* Order Date
* Customer
* Product
* Category
* Region
* Quantity
* Unit Price
* Discount
* Sales
* Profit

## 🔍 Analysis Performed

### Python

* Data cleaning
* Duplicate checking
* Missing-value checking
* Date conversion
* KPI calculation
* Category analysis
* Regional analysis
* Product analysis
* Monthly sales analysis

### SQL

* Sales aggregation
* Profit analysis
* Product analysis
* Regional analysis
* Customer analysis
* Customer segmentation
* Top-performing products and customers

### Power BI

Created an interactive **Sales Performance Dashboard** containing:

* Total Sales
* Total Profit
* Total Orders
* Profit Margin
* Monthly Sales Trend
* Sales by Category
* Sales by Region
* Sales by Product

## 📈 Key Business Insights

* Total Sales: **40.76M**
* Total Profit: **9.12M**
* Total Orders: **1,000**
* Overall Profit Margin: **22.38%**
* **Electronics** is the highest-performing category.
* **West** is the highest-performing region.
* **Laptop** is the top-performing product.
* **April** records the highest monthly sales.

## 💡 Business Recommendations

* Maintain sufficient inventory for high-performing electronics products.
* Focus on the West region while applying successful strategies to other regions.
* Use cross-selling opportunities between laptops and accessories.
* Introduce targeted promotions during lower-sales months.
* Develop bundled offers for lower-performing categories such as Furniture and Accessories.

## 📊 Dashboard

The Power BI dashboard provides an interactive view of sales, profit, orders, products, categories, and regional performance.

The main objective of this project is to demonstrate practical Data Analyst skills, including:

**Data Cleaning → SQL Analysis → Python Analysis → Data Visualization → Power BI Dashboard → Business Insights**
